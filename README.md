#Scalable Batch Data Pipeline for eCommerce Analytics using Azure
Engineered a robust batch data pipeline on Microsoft Azure using Medallion Architecture to process and analyze large-scale eCommerce transactional data.

Built scalable ETL workflows using Azure Data Factory to orchestrate data ingestion and movement across services.

Implemented PySpark in Azure Databricks for distributed data cleaning, transformation, and aggregation.

Applied the Medallion Architecture:

Bronze Layer: Stores raw transactional data.

Silver Layer: Transformed and cleaned data.

Gold Layer: Processed data optimized for business analysis.

Computed key business KPIs including: ✅ Total views and purchases per brand
✅ Daily customer activity trends
✅ Revenue and sales performance per brand

Stored processed data in Azure Data Lake Gen2, optimized for querying with Azure Synapse Analytics.

Created dynamic visual dashboards in Power BI for stakeholder reporting and strategic decision-making.

Ensured data integrity, scalability, and cost-efficiency using modular pipeline design and cloud-native best practices.
